# ADS1015 MakeCode Extension

This extension allows you to use the ADS1015 12-bit ADC with the BBC micro:bit via I2C.

## Features

- 4 single-ended or 2 differential analog inputs
- Programmable gain amplifier (PGA)
- I2C address selection (0x48–0x4B)
- 12-bit resolution (0–4095)
- Voltage conversion helper
- Mode and sample rate configuration
- Read all channels at once
